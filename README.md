# Critter Lab

Standalone development workspace for the **Sampling Arcade multiplayer avatar creator**.

**Main Sampling Arcade remains separate:** https://github.com/chriswalker-afk/Data-Collection

The goal is to develop and test an accessible, quick-to-use animal avatar builder here, then transfer the approved assets and creator into the multiplayer experience. This repository is not the live classroom game.

## Development sequence

1. **Pass 1 — Artwork foundation:** 8 interchangeable heads, 6 bodies, 6 sets of legs, 6 colour palettes, with shared SVG anchors and validation.
2. **Pass 2 — Character creator:** responsive standalone customiser, randomisation, part-by-part recolouring and locally saved choices.
3. **Pass 3 — Combinations and interface audit:** full-part compatibility, keyboard, mobile, small-size and colour checks.
4. **Pass 4 — Multiplayer-ready experience:** lobby, roster and awards mockups, animations and a handover contract.

## Development policy

- Work on feature branches and review pull requests.
- Keep SVG source files, their manifest and validation code together.
- Use only trusted, bundled SVGs; no student image uploads or accounts.
- Do not modify the Data-Collection repository or Cloudflare deployment until the standalone feature is approved.
